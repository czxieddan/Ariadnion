## Integrity rules

- Every retained path begins with the exact package name and version and ends with the original license or notice filename.
- Every SHA-256 value covers the exact stored bytes; byte-identical files remain independently readable under each package version that uses them.
- Registry origins name an exact package version and archive member. Immutable upstream origins include a full Git commit in their URL.
- The forward project/package inventory is `AHCL/AHCL-DEPENDENCIES.md`.
